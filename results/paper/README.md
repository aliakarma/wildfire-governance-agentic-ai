# Paper results — canonical set, metric definitions, caveats

This directory holds the result files behind **every** table and figure in the
manuscript. Each value here is the value printed in `Paper/AAAI/Wildfire.tex`;
[scripts/verify_paper_alignment.py](../../scripts/verify_paper_alignment.py)
checks that cell by cell (354 cells) and fails loudly if the two ever diverge.

Files are produced only by
[scripts/generate_all_paper_results.py](../../scripts/generate_all_paper_results.py),
which aggregates the per-seed metric files in [per_seed/](per_seed/) and evaluates
the closed-form Theorem-2 quantities live. Nothing here is written by hand.

The authoritative artifact map is [MANIFEST.yaml](MANIFEST.yaml)
(machine-readable) and [../../PROVENANCE.md](../../PROVENANCE.md) (human-readable);
the environment parameterisation is in [CALIBRATION.md](CALIBRATION.md).

## Metric definitions

### False public alert rate (F_p)
- **Definition:** false-discovery rate = (# false alerts) / (# alerts broadcast) × 100%.
- **NOT** the classical signal-processing false-positive rate.
- **Computation:** [../../experiments/utils/runner.py](../../experiments/utils/runner.py).

### Detection latency (L_d)
- **Definition:** timesteps from **actual ignition** to first detection
  (confidence > 0.60), measured from the environment-provided ignition time
  (not assumed t = 0).

### Governance compliance
- **Definition:** fraction of episodes with zero governance violations.
- **GOMDP configurations:** 100% by Theorem 1 (environment-level enforcement) —
  definitional, not an independent measurement.
- **Ungoverned configurations:** 0% — equally definitional (there is no gate).
- **Policy-level surrogates:** ~90–93%, the residual in-expectation violation rate.

## CSV-specific notes

### Injection columns (`table2_ablation`, `table3_adversarial`, `table9_multisig`)
- 100 forged-authorization attempts per seed, in three variants (unsigned,
  cryptographically valid signature from a non-validator key, replay of an
  approved certificate), submitted through the same contract entry point a
  legitimate alert traverses.
- **Deterministic per configuration:** with signature verification, 100/100
  blocked; without it, 0/100. This is an **exact** column, checked at 2% tolerance.

### Byzantine / k-sweep (`table5_byzantine_*`, `table6_ksweep`)
- Theory columns are the exact binomial tail of Eq. (4), evaluated live by
  [../../experiments/13_byzantine_compromise.py](../../experiments/13_byzantine_compromise.py)
  and [14_ksweep.py](../../experiments/14_ksweep.py).
- The empirical column of the k-sweep is a Monte-Carlo of the same compromise
  process, fixed at 10,000 trials with seed 1 so it reproduces bit-for-bit.

### Statistical tests (`statistical_tests.csv`)
- Seeds 0–19 are common random numbers across configurations, so all comparisons
  are **paired**; family-wise error is controlled with Holm–Bonferroni.
- The PPO-GOMDP vs PPO-CMDP latency claim is an **equivalence** claim: the
  difference test is non-significant (t(19) = 1.28, p = 0.216) and that alone
  establishes nothing, so it is tested by TOST at the manuscript's pre-specified
  margin Δ = 1.0 step — t_L(19) = 5.55 (p < 0.001), t_U(19) = −2.99 (p = 0.004),
  max(p_L, p_U) = 0.004.

### Learning curve (`fig3_learning_curve.csv`)
- **Training-derived**: the validation L_d curve (mean over 5 held-out seeds)
  behind the Sec. 5.2 convergence claim. Reproduced by rerunning
  [../../experiments/11_ppo_training.py](../../experiments/11_ppo_training.py),
  not by the evaluation aggregator.

## Configuration caveats

- `governance.hitl.rejection_rate: 0.05` — the operator error rate `p_err` of
  Eq. (5); default for all experiments (matches `configs/base.yaml`).
- `blockchain.consensus.mean_delay_steps: 1.2` — a **simulated** consensus model
  (Python), not a Hyperledger Fabric deployment. No Fabric network exists in this
  repository and the manuscript makes no claim based on one.
- Cryptography is **real**: Ed25519 signing/verification and SHA3-256 hashing via
  the `cryptography` library
  ([crypto_utils.py](../../src/wildfire_governance/blockchain/crypto_utils.py)).
  Alert authorisation additionally enforces a registered-validator allowlist and a
  per-event nonce ledger, so injection and replay resistance are measured through
  the same code path a legitimate alert takes.
